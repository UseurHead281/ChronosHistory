# Chronos Stories — локальный аудиоплеер

Исходный проект Android-приложения на Kotlin, Jetpack Compose, Material 3, Room и Media3 ExoPlayer.

## Что уже реализовано в стартовой версии
- Русский интерфейс с разделами «Главная», «Библиотека», «Закладки», «Авторы», «Настройки».
- Импорт одного или нескольких аудиофайлов через системный выбор документов.
- Локальная база Room для произведений, прогресса и закладок.
- Переименование произведения и редактирование автора.
- Воспроизведение через Media3, фоновый `MediaSessionService` и системные медиакоманды.
- Сохранение позиции воспроизведения с периодическим обновлением и при паузе.
- Перемотка назад/вперёд, изменение скорости, добавление и переход к закладкам.
- Переключение светлой/тёмной/AMOLED-темы и базовые параметры плеера.
- Приватность: приложение не отправляет аудио или статистику на сервер.

## Требования
- Android Studio с JDK 17.
- Android SDK 35.
- Интернет при первой сборке для загрузки Gradle и библиотек.
- `minSdk = 26` (Android 8.0).

## Сборка APK
1. Распакуйте архив.
2. Откройте папку `ChronosStories` в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите **Build → Build APK(s)**.
5. APK для отладки появится в `app/build/outputs/apk/debug/app-debug.apk`.

В этом архиве не вложен Gradle Wrapper JAR и APK: они должны быть сгенерированы/скачаны средой сборки. APK здесь не собирался и не проверялся на устройстве.

## Сборка с телефона через GitHub Actions
В архив добавлен workflow `.github/workflows/android.yml`, который собирает debug APK в облаке GitHub Actions.

1. Распакуй архив и загрузи файлы проекта в новый GitHub-репозиторий (важно: папка `.github/workflows` тоже должна попасть в репозиторий).
2. Открой вкладку **Actions** в репозитории.
3. Если запуск не стартовал автоматически, выбери **Build Android APK** → **Run workflow**.
4. После успешного запуска открой выполненный workflow, найди раздел **Artifacts** и скачай `chronos-stories-debug-apk`.
5. Распакуй скачанный артефакт и установи APK на телефон, разрешив установку из выбранного источника, если Android попросит.

Сборка в облаке требует доступа к GitHub и интернету. Сам workflow включён в архив, но в этой среде он не запускался, поэтому успешность сборки пока не подтверждена.
